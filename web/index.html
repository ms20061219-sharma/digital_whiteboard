Software Architecture & OOP Design

Demonstrating textbook Object-Oriented Programming and Design Patterns.

🏛️ Strategy Pattern (Polymorphism)

DrawingTool interface defines the drawing contract. BrushTool, EraserTool, ShapeTool, and TextTool implement polymorphic behavior dynamically swapped at runtime.

🖼️ Off-Screen Double Buffering

Artwork is rendered onto an off-screen BufferedImage buffer. paintComponent(Graphics g) draws the buffer, preventing any flickering or lost drawings during window resize or repaint.

🎯 Event-Driven Decoupling

CanvasMouseHandler captures mouse press, drag, release, and move events, forwarding them to the active tool while decoupling UI mechanics from business logic.

🛡️ Exception Handling & File I/O

FileManager wraps image reading/writing in try-catch-finally blocks, gracefully handling IOException with interactive error alerts.
